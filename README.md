## Updating the site

The site is a single Jekyll page that GitHub Pages builds on every push to `main`; there is nothing to install.

- **Content** lives in `index.html`, one `<section>` per part of the page (About, Experience, Education, Teaching & Outreach, Publications).
- **A new paper:** copy one `<li class="pub">` in the Publications section and edit it. `data-tags` takes any of `physics`, `hpc`, `quantum`; the filter buttons and their counts update by themselves.
- **A new course, talk or demo:** copy a `<li>` in the matching card of the Teaching & Outreach section.
- **Navigation, footer links and the footer quote** are in `_config.yml`.
- **Styles** are in `assets/css/site.css`; the hero animation is `assets/js/hero.js`; the theme toggle, field selector and publication filter are in `assets/js/site.js`.
- The old page addresses (`/experience.html`, `/publications.html`, …) redirect to the matching section, so existing links keep working.
