Work Experience

  • Advanced Quantum Software Engineer
    IQM Quantum Computers, Munich, Germany (Oct 2025 - present)

    • Designed the end-to-end backend pipeline for compiling and submitting quantum circuits to IQM's quantum hardware. Leading the architectural design of several Qrisp new features.

    • Wrote roadmaps, ADRs, and contributing guidelines. Coordinated refactoring projects across 10+ developers to enforce optimal design patterns and code quality standards across the Qrisp codebase.

    • Core contributor to Qrisp, IQM's adopted open-source high-level Python framework for writing and compiling quantum circuits. Implemented core features and algorithms, especially in Just-in-Time (JIT) compilation mode with JAX.

    • Presenting the tutorial Eclipse Qrisp: High-Level Quantum Programming for Dynamic Algorithms at IEEE Quantum Week 2026 in Toronto, on writing dynamic quantum algorithms with Qrisp.

    • Authored Solving the MaxCut problem with QAOA using Qrisp, a hands-on notebook published on the IQM Academy that runs on IQM quantum hardware.

  • Quantum Software Developer II
    Xanadu Quantum Technologies, Toronto, ON, Canada (Feb 2024 - Oct 2025)

    • Contributed to a multi-year effort to capture the entire PennyLane workflow into the JAX computational graph for JIT quantum compilation, accelerating quantum machine learning pipelines. Prototyped a Python compiler based on MLIR to apply quantum transforms as compilation passes.

    • Developed DefaultTensor, a PennyLane quantum device based on tensor network simulations, enabling the simulation of quantum circuits with thousands of gates. The public tutorial is available on the PennyLane website.

    • Core team release manager for PennyLane 0.41 and PennyLane 0.40, and several PennyLane plugins. Mentored Ph.D. residents during onboarding. Wrote documentation, tutorials, and guides for users.

    • Core contributor (300+ commits) to PennyLane, a leading open-source Python/C++ framework for quantum machine learning with 3000+ GitHub stars and 800+ forks.
